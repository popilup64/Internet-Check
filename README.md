# 🌐 Internet Check

Простое приложение для проверки доступности интернета и определения активности белых списков (ТСПУ). Проверяет несколько популярных сайтов и показывает результат с визуальным оформлением.

## 📱 Скриншоты

| Интернет есть | Белый список ВКЛЮЧЕН | Интернета нет |
|---------------|---------------------|---------------|
| 🟢 Зеленый фон | 🟠 Оранжевый фон | 🔴 Красный фон |
| ✅ Доступен | ❌ Заблокировано | ❌ Недоступен |

## ✨ Возможности

- ✅ Проверка доступности Интернета
- 🎨 Визуальная индикация (зеленый/оранжевый/красный фон)
- 🔍 Определение активности белых списков (ТСПУ)
- 📱 Простой и понятный интерфейс
- ⚡ Быстрая проверка (3 секунды таймаут)
- 🔄 Асинхронная проверка (не блокирует UI)
- 📊 Виджет на рабочий стол с цветовой индикацией
- 🔄 Автоматическое обновление виджета каждые 30 минут
