# 🌐 Internet Check
Простое приложение для проверки доступности интернета. Проверяет несколько популярных сайтов и показывает результат с визуальным оформлением.

## 📱 Скриншоты

| Интернет есть | Интернета нет |
|---------------|----------------|
| 🟢 Зеленый фон | 🔴 Красный фон |
| ✅ Доступен | ❌ Недоступен |

## ✨ Возможности

- ✅ Проверка доступности нескольких сайтов
- 🎨 Визуальная индикация (зеленый/красный фон)
- 📱 Простой и понятный интерфейс
- ⚡ Быстрая проверка (5 секунд таймаут)
- 🔄 Асинхронная проверка (не блокирует UI)
